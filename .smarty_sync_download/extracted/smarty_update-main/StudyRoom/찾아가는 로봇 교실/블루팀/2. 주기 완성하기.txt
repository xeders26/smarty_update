<h2 style="color: #3498db; margin: 0 0 5px 0;">📱 심화 예제: 블루투스 다중 제어 (메카넘휠 & 슬라이드)</h2>
<hr style="margin: 5px 0 15px 0; border-color: #555;">

<p style="margin: 0 0 15px 0; line-height: 1.4;">스마트폰에서 보낸 명령어를 분석하여, <b>메카넘휠의 이동 방향과 속도를 제어</b>하거나 <b>특정 조건에서 슬라이드 모터를 작동</b>시키는 심화 조종 예제입니다. 명령어(알파벳)와 데이터(숫자)를 조합하여 로봇의 다양한 부품을 동시에 제어하는 방법을 배울 수 있습니다.</p>

<h3 style="color: #3498db; margin: 0 0 10px 0;">🧩 블록 동작 흐름</h3>
<ol style="line-height: 1.4; margin: 0 0 15px 25px; padding: 0;">
  <li style="margin-bottom: 5px;"><b>스마티 시작 및 변수 설정:</b> 통신을 준비하고, 로봇의 속도를 기억할 'power' 변수를 0으로 설정합니다.</li>
  <li style="margin-bottom: 5px;"><b>블루투스 수신 및 분리:</b> 스마트폰에서 데이터가 오면, 알파벳은 <b>'cmd' 변수</b>에, 숫자는 <b>'value' 변수</b>에 쪼개서 저장합니다.</li>
  <li style="margin-bottom: 5px;"><b>"D" 명령어 (이동):</b> 만약 명령어가 <b>"D"</b>라면, 함께 온 숫자(value)를 '이동 방향'으로, 현재 기억된 'power' 값을 '속도'로 사용하여 메카넘휠을 굴립니다.</li>
  <li style="margin-bottom: 5px;"><b>"F" 명령어 (특수 동작):</b> 만약 명령어가 <b>"F"</b>이고 수신된 숫자(value)가 <b>정확히 11</b>이라면, 파란색 슬라이드 모터를 0도로 움직입니다.</li>
  <li style="margin-bottom: 5px;"><b>"P" 명령어 (파워 설정):</b> 만약 명령어가 <b>"P"</b>라면, 수신된 숫자(value)를 'power' 변수에 저장하여 앞으로의 이동 속도를 갱신합니다.</li>
  <li><b>10 밀리초(ms) 기다리기:</b> 통신 딜레이나 끊김을 방지하기 위해 0.01초(10ms) 동안 아주 짧게 대기하며 안정을 취합니다.</li>
</ol>
