<h2 style="color: #3498db; margin: 0 0 5px 0;">📱 통신 예제: 블루투스 명령으로 로봇 조종하기</h2>
<hr style="margin: 5px 0 15px 0; border-color: #555;">

<p style="margin: 0 0 15px 0; line-height: 1.4;">스마트폰 앱을 통해 블루투스로 명령을 받고, 수신된 글자(명령어)에 따라 스마티 로봇을 움직이거나 상태 변수를 변경하는 <b>고급 통신 예제</b>입니다. 명령어와 숫자를 분리해서 받는 구조로 되어 있어, 다양한 조종 앱을 만들 때 뼈대로 사용하기 아주 좋습니다.</p>

<h3 style="color: #3498db; margin: 0 0 10px 0;">🧩 블록 동작 흐름</h3>
<ol style="line-height: 1.4; margin: 0 0 15px 25px; padding: 0;">
  <li style="margin-bottom: 5px;"><b>스마티 시작 및 변수 설정:</b> 블루투스 통신을 준비하고, 로봇의 파워를 기억할 'power' 변수를 만들어 0으로 설정합니다.</li>
  <li style="margin-bottom: 5px;"><b>블루투스 수신 확인:</b> 스마트폰에서 로봇으로 보낸 데이터(명령)가 도착했는지 계속해서 확인합니다.</li>
  <li style="margin-bottom: 5px;"><b>수신된 데이터 분리:</b> 도착한 데이터에서 명령어 글자는 <b>'cmd' 변수</b>에, 뒤따라온 숫자는 <b>'value' 변수</b>에 각각 쪼개서 저장합니다.</li>
  <li style="margin-bottom: 5px;"><b>명령어(cmd)에 따른 행동 결정:</b> 만약 명령어가 <b>"D"</b>라면 메카넘휠 이동 블록(속도 500)을 실행하고, <b>"P"</b>라면 함께 전달된 숫자(value)를 'power' 변수에 저장하여 기억합니다.</li>
  <li><b>10 밀리초(ms) 기다리기:</b> 통신이 너무 빠르게 연속으로 일어나 데이터가 꼬이는 것을 방지하기 위해 0.01초(10ms) 동안 아주 짧게 대기합니다.</li>
</ol>
