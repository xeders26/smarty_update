<h2 style="color: #3498db; margin: 0 0 5px 0;">📱 심화 예제: 블루투스 다중 제어 (슬라이드 모터 확장)</h2>
<hr style="margin: 5px 0 15px 0; border-color: #555;">

<p style="margin: 0 0 15px 0; line-height: 1.4;">스마트폰에서 보낸 명령어를 분석하여 메카넘휠을 조종하고, 특정 숫자 신호에 따라 <b>슬라이드 모터의 각도를 정밀하게 제어</b>하는 심화 예제입니다. 비어있는 조건을 스스로 완성하며 코딩 실력을 키워볼 수 있습니다.</p>

<h3 style="color: #3498db; margin: 0 0 10px 0;">🧩 블록 동작 흐름</h3>
<ol style="line-height: 1.4; margin: 0 0 15px 25px; padding: 0;">
  <li style="margin-bottom: 5px;"><b>스마티 시작 및 변수 설정:</b> 통신을 준비하고, 로봇의 속도를 기억할 'power' 변수를 0으로 설정합니다.</li>
  <li style="margin-bottom: 5px;"><b>블루투스 수신 및 분리:</b> 스마트폰에서 데이터가 도착하면, 명령어(알파벳)는 <b>'cmd'</b>에, 숫자 값은 <b>'value'</b> 변수에 각각 나누어 저장합니다.</li>
  <li style="margin-bottom: 5px;"><b>"D" 명령어 (이동):</b> 명령어가 <b>"D"</b>라면, 수신된 숫자(value) 방향으로 현재 기억된 속도(power)만큼 메카넘휠을 굴립니다.</li>
  <li style="margin-bottom: 5px;"><b>"F" 명령어 (특수 동작):</b> 만약 명령어가 <b>"F"</b>일 때, 수신된 숫자(value)가 <b>11이라면</b> 파란색 슬라이드 모터를 <b>35도</b>로 움직입니다. 만약 숫자가 <b>0이라면?</b> (현재는 비어있습니다!)</li>
  <li style="margin-bottom: 5px;"><b>"P" 명령어 (파워 설정):</b> 만약 명령어가 <b>"P"</b>라면, 수신된 숫자를 'power' 변수에 저장하여 앞으로의 이동 속도를 변경합니다.</li>
  <li><b>10 밀리초(ms) 기다리기:</b> 통신 과부하를 막기 위해 0.01초(10ms) 동안 아주 짧게 대기합니다.</li>
</ol>
