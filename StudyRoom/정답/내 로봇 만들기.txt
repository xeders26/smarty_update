<h2 style="color: #3498db; margin: 0 0 5px 0;">📱 심화 예제: 블루투스로 스마트 로봇 원격 조종하기</h2>
<hr style="margin: 5px 0 15px 0; border-color: #555;">

<p style="margin: 0 0 15px 0; line-height: 1.5;">스마트폰이나 블루투스 조종기에서 전송된 <b>명령어(문자)</b>와 <b>값(숫자)</b>을 분석하여, 스마티 로봇을 이동시키거나 로봇팔을 움직이는 심화 예제입니다.<br>
기기 간에 데이터를 어떻게 쪼개고 해석하여 동작으로 연결하는지(프로토콜 통신)를 배울 수 있습니다.</p>

<h3 style="color: #3498db; margin: 0 0 10px 0;">🧩 블록 동작 흐름</h3>
<ol style="line-height: 1.5; margin: 0 0 15px 25px; padding: 0;">
  <li style="margin-bottom: 5px;"><b>초기 설정 (setup):</b> 스마티 로봇과 블루투스 모듈을 켜고, 파란색 로봇팔(슬라이드와 집게)의 위치를 초기 각도(0)로 맞춥니다. 기본 이동 속도인 <code style="color: #f1c40f;">power</code> 변수도 0으로 준비합니다.</li>
  <li style="margin-bottom: 5px;"><b>데이터 수신 대기:</b> 무한 반복(loop) 안에서 <code style="color: #f1c40f;">[블루투스 데이터가 있는가?]</code> 블록으로 조종기에서 온 신호가 있는지 확인합니다.</li>
  <li style="margin-bottom: 5px;"><b>명령(cmd)과 값(value) 분류:</b> 신호가 들어오면 문자는 <code style="color: #f1c40f;">cmd</code> 변수에, 숫자는 <code style="color: #f1c40f;">value</code> 변수에 나누어 저장합니다.</li>
  <li style="margin-bottom: 5px;"><b>명령어 분석 및 실행 (만약 ~라면):</b>
    <ul style="margin-top: 5px; margin-bottom: 5px; padding-left: 20px;">
      <li><b>명령이 "D" (Drive) 이면:</b> 전달받은 방향(<code style="color: #f1c40f;">value</code>)과 현재 저장된 속도(<code style="color: #f1c40f;">power</code>)로 메카넘 휠을 굴려 로봇을 이동시킵니다.</li>
      <li><b>명령이 "F" (Function) 이면:</b> 전달받은 값(<code style="color: #f1c40f;">value</code>)에 따라 파란색 로봇팔을 제어합니다. (예: 11=슬라이드 40도 올리기, 10=슬라이드 내리기, 21=집게 90도 닫기, 20=집게 열기)</li>
      <li><b>명령이 "P" (Power) 이면:</b> 전달받은 숫자로 로봇의 기본 이동 속도(<code style="color: #f1c40f;">power</code> 변수)를 변경합니다.</li>
    </ul>
  </li>
  <li><b>안정화 대기:</b> 통신 오류나 모터의 과부하를 막기 위해 아주 짧게(10ms) 쉰 후, 다시 새로운 명령을 기다립니다.</li>
</ol>

<div style="background: rgba(255, 255, 255, 0.05); padding: 12px; border-left: 4px solid #f39c12; border-radius: 4px; margin-top: 15px;">
  <b style="color: #f39c12;">💡 핵심 포인트</b>
  <div style="margin-top: 5px; color: #e0e0e0; line-height: 1.5;">명령어의 종류를 나타내는 <b>알파벳(cmd)</b>과 동작의 디테일을 나타내는 <b>숫자(value)</b>를 조합하는 방식은 실제 드론이나 로봇을 조종할 때 사용하는 아주 훌륭한 통신 방식입니다.<br><br>※ 스마트폰 조종기 앱에서 <code>D 1</code>(전진), <code>P 800</code>(속도 800 설정), <code>F 21</code>(집게 닫기) 처럼 데이터를 날리면 로봇이 똑똑하게 반응하는 것을 확인할 수 있습니다! 나만의 명령어를 더 추가해 보세요.</div>
